Wikilokal menghubungkan Wikipedia, Wikimedia Commons, Wikidata, dan OpenStreetMap berdasarkan lokasi. Kini ditulis ulang dengan Kotlin Multiplatform: satu basis kode untuk Android, Windows, macOS, dan segera iOS.Wikilokal links Wikipedia, Wikimedia Commons, Wikidata and OpenStreetMap by location. Now rebuilt on Kotlin Multiplatform: one codebase for Android, Windows, macOS and, soon, iOS.

Kotlin Multiplatform

Dari satu aplikasi menjadi satu basis kodeFrom one app to one codebase

Versi 2.0.0 adalah transformasi besar: logika dan antarmuka dipakai bersama, sementara tiap platform tetap terasa asli.Version 2.0.0 is a major transformation: logic and UI are shared, while each platform still feels native.

  • Satu logika, empat target: fitur baru cukup ditulis sekali, lalu hadir di Android, Windows, macOS, dan iOS.One logic, four targets: write a feature once and it lands on Android, Windows, macOS and iOS.
  • Pengalaman konsisten: pengguna desktop dan seluler mendapat fitur yang sama pada waktu yang sama.Consistent experience: desktop and mobile users get the same features at the same time.
  • Pemeliharaan lebih ringan: satu perbaikan bug berlaku untuk semua platform.Easier upkeep: one bug fix applies to every platform.

Pertanyaan yang sering munculFrequently asked questions

Apakah ini aplikasi resmi Wikimedia?Is this an official Wikimedia app?

Bukan. Wikilokal adalah proyek independen yang memakai API publik proyek Wikimedia dan OpenStreetMap. Wikimedia adalah merek Wikimedia Foundation. Dikembangkan dan dikelola oleh Affandy Murad.No. Wikilokal is an independent project using public APIs of Wikimedia projects and OpenStreetMap. Wikimedia is a trademark of the Wikimedia Foundation. Developed and maintained by Affandy Murad.

Apa yang berubah di versi 2.0.0?What changed in 2.0.0?

Aplikasi dibangun ulang dengan Kotlin Multiplatform sehingga satu basis kode melayani Android, Windows, macOS, dan nantinya iOS.The app was rebuilt with Kotlin Multiplatform so one codebase serves Android, Windows, macOS and, later, iOS.

Kapan iOS tersedia?When will iOS be available?

Belum ada tanggal pasti. Pantau halaman ini dan situs utama untuk kabar terbaru.There is no firm date yet. Watch this page and the main website for updates.

Windows/macOS menampilkan peringatan keamanan. Aman?Windows/macOS shows a security warning. Is it safe?

Berkas desktop belum ditandatangani sertifikat pengembang berbayar, jadi sistem operasi bisa memperingatkan. Unduh hanya dari tautan di halaman ini. Di macOS, klik kanan lalu pilih Open; di Windows, pilih “More info” lalu “Run anyway”.The desktop files are not yet signed with a paid developer certificate, so the OS may warn you. Download only from links on this page. On macOS, right-click and choose Open; on Windows, choose “More info” then “Run anyway”.

Bagaimana cara melihat versi web?Is there a web version?

Ya, buka wikilokal.netlify.app.Yes, open wikilokal.netlify.app.
