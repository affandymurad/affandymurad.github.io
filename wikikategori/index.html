Penelusur Kategori Wikipedia

← Kembali ke Affandy Murad

Telusuri artikel dalam satu kategori Wikipedia, atau cari di bahasa mana saja sebuah artikel tersedia. Keduanya memakai MediaWiki API dan Wikidata untuk menautkan padanan antarbahasa.

Kode bahasa mengikuti subdomain Wikipedia (id, en, ja, fr, de, dst). Prefiks namespace kategori (mis. "Kategori:", "Category:") tidak perlu diketik.
