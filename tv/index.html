How it's calculated. Screen width & height are derived from the diagonal (inches × 2.54 cm) using a 16:9 ratio via the Pythagorean theorem. A4 paper = 21.0 × 29.7 cm. Stand height is assumed to be ≈9 cm for every size — the real figure varies by model and brand.
  • The A4 paper tiles on the screen show how many sheets are needed to cover the width (top row) and height (left column) of the screen; any leftover fraction is marked with a dashed tile.
  • The diagram is drawn proportionally 1:1 in centimeters (not pixels), so the ratios between elements are accurate.
